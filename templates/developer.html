📄 API Documentation

This REST API allows external spacesuit biosensors to push telemetry directly to the AstroHealth AI database. Mission Control can monitor this data in real-time.

POST /api/v1/sensor_ingest

Expected Payload Format (JSON)

{ "heart_rate": 85, "systolic_bp": 120, "diastolic_bp": 80, "spo2": 97, "body_temp": 36.8, "sleep_hours": 7.5, "activity_minutes": 45, "radiation_mSv": 0.5 }
